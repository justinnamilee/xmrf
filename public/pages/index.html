Regex-map Rename File · Signed APT, RPM, Alpine and Arch repositories.

XMRF (Regex-map Rename File) is a powerful, lightweight command-line utility for batch renaming, moving, and organizing files using regular expressions and flexible formatting rules. Written in Perl using only core modules, XMRF supports recursive processing, custom transformations, and a safe preview mode.

For documentation, examples, and source code, visit XMRF on GitHub ↗

Quick Start

Install XMRF for your distribution.

One installer · APT / DNF / APK / Pacman

Detects your distribution, verifies signing keys, and configures updates.

curl -fsSL https://xmrf.taiz.me/install.sh | sudo sh

On Alpine, run as root using the built-in wget:

wget -qO- https://xmrf.taiz.me/install.sh | sh
curl -fsSLO https://xmrf.taiz.me/install.sh less install.sh sudo sh install.sh

On Alpine, download with wget, review the file, then run sh install.sh as root.

Arch installation performs a full system upgrade with pacman -Syu.

Review install.sh before running it. Existing aliases remain available: APT · DNF · APK · Pacman.
