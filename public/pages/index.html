Quick Start

Install XMRF for your distribution.

Debian / Ubuntu Based
curl -fsSL https://justinnamilee.github.io/xmrf/install-apt.sh | sudo bash
curl -fsSLO https://justinnamilee.github.io/xmrf/install-apt.sh less install-apt.sh sudo bash install-apt.sh
Fedora / RHEL Based
curl -fsSL https://justinnamilee.github.io/xmrf/install-dnf.sh | sudo bash
curl -fsSLO https://justinnamilee.github.io/xmrf/install-dnf.sh less install-dnf.sh sudo bash install-dnf.sh

Please review scripts before running them: APT · DNF
