    .
    ├── ansible
    │   └── package

    ├── linux

    │   │   └── xmrf-via-github-releases
    │   └── source

## DESCRIPTION

This folder contains playbooks and scripts that can be used to install XMRF on
various systems in a more automated fashion.  The least-janky of which is the
Ansible playbook.
